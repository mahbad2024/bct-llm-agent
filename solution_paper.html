1. Executive Summary

We present a dual-agent LLM system for user modeling and personalized recommendation, specifically adapted for Nigerian users. Our solution addresses both competition tasks:

  • Task A (User Modeling): Simulates realistic user reviews with accurate ratings and Nigerian Pidgin, achieving 0.87 BERTScore and 0.55 RMSE
  • Task B (Recommendation): Delivers contextual, cross-domain recommendations with cold-start handling, achieving 0.67 NDCG@10

Key Innovations:

  1. Few-shot prompting using 177,193 real reviews from Amazon, Yelp, AND Goodreads
  2. Hybrid rating predictor (RandomForest ML model + rule-based fallback)
  3. Nigerian Pidgin and cultural context integration
  4. Multi-turn conversational cold-start handling

2.2 Task A: User Modeling (Review Generation)

Approach: Few-shot prompting with retrieved examples + rating prediction

Rating Predictor Features:

  • User: age, price sensitivity, spice preference, interests
  • Product: price, category, description keywords
  • Model: RandomForest Regressor trained on 20,000 samples

2.3 Task B: Recommendation

Approach: Hybrid (LLM + Rule-based + Cold-start)

Cold-Start Strategy:

  • No interests → Ask clarifying questions (multi-turn)
  • Has interests → Recommend from popular items per category
  • Cross-domain → Suggest items from related categories

5. Nigerian Context Adaptation (Bonus)

We implemented specific adaptations for the bonus marks:

  • Language: Nigerian Pidgin phrases ("dey sweet", "abeg o", "well well", "the thing soft", "Omo!", "na wa o", "Chai!", "God bless you")
  • Pricing: Nigerian Naira (₦) currency
  • Locations: Lagos, Abuja, Yaba, Port Harcourt, Ibadan, Benin
  • Cultural items: Jollof Rice, Suya, Pounded Yam, Jumia, Showmax
  • Price Sensitivity: Phrases like "my money no waste", "e be pricey small"
  • Spice Preference: Phrases like "pepper body", "e dey hot well"

Example Prompt:

"Write as a 22-year-old UNILAG student in Yaba. Price sensitive (student budget). Use phrases like 'the thing soft well well' for good products."
